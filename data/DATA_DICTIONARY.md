# Data dictionary

| Column | Description |
|---|---|
| `Order_ID` | Unique sample order-line identifier |
| `Order_Date` | Date of the order |
| `Region` | Sample sales region |
| `Category` | Product category |
| `Product` | Product name |
| `Customer_Segment` | Consumer, Corporate, or Home Office |
| `Quantity` | Number of units |
| `Unit_Price` | Sample unit price before discount |
| `Discount` | Discount rate, stored as a decimal |
| `Revenue` | Quantity × unit price after discount |
| `Profit` | Synthetic profit estimate for demonstration |
